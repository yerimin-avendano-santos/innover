# INMOVER (PropMap 3D) 🏢🗺️

Una plataforma inmobiliaria PropTech "todo en uno" basada en mapas interactivos y recorridos en 3D. Este proyecto no solo busca transformar el mercado inmobiliario, sino que también está diseñado como un **proyecto de aprendizaje progresivo (Open Source)** para enseñar desarrollo Full-Stack desde cero.

## 🚀 Propuesta de Valor
Optimizar la búsqueda de propiedades para el usuario final mediante mapas y visualización 3D, y proveer un CRM avanzado para agentes inmobiliarios.

### Características Clave:
- **Mapa Interactivo:** Visualización geográfica de propiedades (alquiler/venta).
- **Inmersión 3D:** Renderizados y tours virtuales detallados.
- **B2B CRM:** Herramienta para agentes inmobiliarios (gestión de cartera y prospectos).
- **Directorio de Propietarios:** Conexión directa con validación de identidad.
- **Asistente Virtual IA:** Chatbot asesor para recomendaciones personalizadas e información financiera.

## 📚 Proyecto de Aprendizaje
Este repositorio está documentado paso a paso para que cualquier desarrollador junior pueda seguir la evolución de una Startup PropTech, aprendiendo:
- Arquitectura de Software
- Backend y Bases de Datos Geoespaciales
- Frontend y Mapas
- Seguridad y Autenticación
- Integración de IA

👉 **Mira nuestro plan de estudio y desarrollo en:** [docs/ROADMAP.md](./docs/ROADMAP.md)

## 🛠️ Stack Tecnológico Elegido
- **Lenguaje Principal:** JavaScript / TypeScript
- **Frontend (Interfaz y Mapas):** React.js / Next.js
- **Backend (Servidor y APIs):** Node.js con Express o NestJS
- **Base de Datos:** PostgreSQL con extensión PostGIS (para los datos geográficos)
- **Mapas:** Mapbox o Google Maps API
